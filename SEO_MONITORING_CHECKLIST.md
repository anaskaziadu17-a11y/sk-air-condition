## Common Mistakes to Avoid

```
❌ DON'T: Keyword stuffing (overusing keyword)
✅ DO: Write naturally with 1-2% keyword density

❌ DON'T: Duplicate content across pages
✅ DO: Unique content for each page

❌ DON'T: Hide content with display: none
✅ DO: Make content visible to users and crawlers

❌ DON'T: Build backlinks too fast (looks spammy)
✅ DO: Build links gradually and naturally

❌ DON'T: Ignore mobile experience
✅ DO: Test everything on mobile

❌ DON'T: Forget to monitor rankings
✅ DO: Track metrics weekly in Search Console

❌ DON'T: Update old content without redirects
✅ DO: Set up 301 redirects for old pages

❌ DON'T: Ignore user experience
✅ DO: Make site fast, responsive, and easy to use
```

## Tools for Monitoring

### Free Tools
```
1. Google Search Console
   https://search.google.com/search-console
   Use for: Rankings, impressions, clicks, errors

2. Google Analytics 4
   https://analytics.google.com/
   Use for: Traffic, user behavior, conversions

3. Mobile-Friendly Test
   https://search.google.com/test/mobile-friendly
   Use for: Check mobile compatibility

4. Rich Results Test
   https://search.google.com/test/rich-results
   Use for: Check structured data validation

5. PageSpeed Insights
   https://pagespeed.web.dev/
   Use for: Page speed analysis

6. Schema.org Validator
   https://validator.schema.org/
   Use for: Validate JSON-LD markup
```

```
1. SEMrush ($120/month)
   - Rank tracking for target keywords

   - Local rank tracking

   - WordPress plugin (if using WordPress)
   - On-page SEO optimization
```
